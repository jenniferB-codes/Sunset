WILLOW & LINEN - DEMO FRONTEND

Abre index.html en tu navegador o usa Live Server en VS Code.
Páginas: index.html, picnics.html, brunches.html, como-funciona.html, galeria.html, reservar.html.
El flujo de reserva es: paquete > actividad > datos.
Las fotos se cargan desde Unsplash y requieren conexión a internet.
Los precios son ilustrativos. La reserva NO se envía ni se almacena en un servidor.
Para aceptar reservas reales hay que integrar un backend, validar datos en el servidor y configurar correo/base de datos.
